Executive Summary & Abstract

In today's fast-paced digital business ecosystem, small and medium enterprises (SMEs) face immense friction managing customer touchpoints across fragmented communication channels. Disconnected spreadsheets, delayed follow-ups, and lack of real-time sales visibility result in reduced deal conversions and administrative overhead.

CRM360 addresses these challenges by delivering a centralized, scalable, multi-tenant SaaS Customer Relationship Management platform. Engineered using the MERN stack (MongoDB, Express.js, React.js, Node.js), the platform integrates:

  • Role-Based Access Control (RBAC) across Admin, Sales Manager, and Sales Executive tiers.
  • Interactive Executive Dashboard featuring real-time KPI aggregations, conversion metrics, and visual pipeline progression.
  • Customer Directory & 360° Dossier with server-side pagination, multi-field regex search, and relational entity population.
  • Sales Opportunity Pipeline with both Kanban board and tabular views supporting deal velocity tracking across six progressive stages.
  • Operational Task Management with priority coding, overdue detection, and polymorphic entity linking.
  • Zero-Comment Code Integrity maintaining strict production-grade syntax and decoupled state stores via Zustand.

2. Database Schema & Data Models

User Model (models/User.js)

Manages organizational identity and credentials. Utilizes a Mongoose pre-save hook to hash passwords using Bcrypt with 10 salt rounds and provides an instance method comparePassword() for authentication.

{
  name: { type: String, required: true, trim: true },
  email: { type: String, required: true, unique: true, lowercase: true },
  password: { type: String, required: true, minlength: 6 },
  role: { type: String, enum: ['Admin', 'Sales Manager', 'Sales Executive'], default: 'Sales Executive' },
  createdAt: { type: Date, default: Date.now }
}

Customer Model (models/Customer.js)

Stores enterprise and direct client records with timestamps, communication channels, physical location, and user attribution.

{
  name: { type: String, required: true },
  email: { type: String, required: true, lowercase: true },
  phone: { type: String, default: '' },
  company: { type: String, default: '' },
  address: { type: String, default: '' },
  city: { type: String, default: '' },
  state: { type: String, default: '' },
  zip: { type: String, default: '' },
  notes: { type: String, default: '' },
  createdBy: { type: ObjectId, ref: 'User', required: true }
}

Lead Model (models/Lead.js)

Tracks sales opportunities across pipeline stages: New, Contacted, Qualified, Proposal Sent, Won, and Lost with financial valuations.

{
  title: { type: String, required: true },
  customer: { type: ObjectId, ref: 'Customer', default: null },
  status: { type: String, enum: ['New', 'Contacted', 'Qualified', 'Proposal Sent', 'Won', 'Lost'], default: 'New' },
  value: { type: Number, default: 0, min: 0 },
  assignedTo: { type: ObjectId, ref: 'User', default: null },
  notes: { type: String, default: '' },
  followUpDate: { type: Date, default: null },
  createdBy: { type: ObjectId, ref: 'User', required: true }
}

Task Model (models/Task.js)

Facilitates team action items with priority weights, deadlines, and dynamic polymorphic linkages to either a Customer or a Lead.

{
  title: { type: String, required: true },
  description: { type: String, default: '' },
  assignedTo: { type: ObjectId, ref: 'User', default: null },
  status: { type: String, enum: ['Pending', 'In Progress', 'Completed'], default: 'Pending' },
  dueDate: { type: Date, default: null },
  priority: { type: String, enum: ['Low', 'Medium', 'High'], default: 'Medium' },
  relatedTo: { type: String, enum: ['Customer', 'Lead'], default: null },
  relatedToId: { type: ObjectId, refPath: 'relatedTo', default: null },
  createdBy: { type: ObjectId, ref: 'User', required: true }
}

3. REST API Specification

Method Endpoint Access Level Description & Business Outcome
POST /api/auth/register Public Registers user with hashed password and returns JWT token.
POST /api/auth/login Public Authenticates email/password, auto-seeds if fresh, returns token.
GET /api/auth/me Protected Retrieves the verified user profile based on Bearer token.
GET /api/auth/users Protected Fetches list of team members for task and lead assignments.
POST /api/auth/seed Public Idempotent endpoint to populate/reset initial demo database.
GET /api/customers Protected Retrieves paginated customers supporting regex search.
GET /api/customers/:id Protected Retrieves single customer with populated leads and tasks.
POST /api/customers Protected Creates a new customer linked to authenticated user.
PUT /api/customers/:id Protected Updates customer details while preserving immutable creator ref.
DELETE /api/customers/:id Protected Cascading deletion: removes customer and cleans dependencies.
GET /api/leads Protected Lists deals filtered by pipeline status and assigned member.
POST /api/leads Protected Creates a new sales opportunity with monetary valuation.
PATCH /api/leads/:id/status Protected Atomic stage promotion (e.g. Qualified to Proposal Sent to Won).
GET /api/tasks Protected Lists tasks sorted by urgency and filtered by priority/assignee.
PATCH /api/tasks/:id/status Protected Single-click task toggle (Pending, In Progress, Completed).
GET /api/dashboard/metrics Protected Calculates KPI metrics: Total Customers, Active Leads, Deal Value.
GET /api/dashboard/sales-pipeline Protected Groups deals by stage with conversion rate percentages.
GET /api/dashboard/recent-activities Protected Aggregates latest 10 team actions into an activity stream.
